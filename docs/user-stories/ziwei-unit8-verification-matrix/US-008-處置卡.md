# US-008：處置卡

**作為** 學員  
**我想要** 處置卡模板與 3 張預填卡  
**以便** 每個未通過列都有暫時措施與重新驗測條件，並交給單元 9

**輸入格式**：
- spec §2 FR-7；Notion §7.4、§7.5、§13

**輸出格式**：
- `docs/unit8/disposition-cards.md`

**驗收條件**：
- [ ] 模板 8 欄：問題、影響範圍、交易證據、優先級（阻斷／人工接手／可延後）、暫時措施、處理人、重新驗測條件、上線狀態（可繼續測試／修正後開放／暫停入口）
- [ ] 3 張預填卡：PeriodReturnURL 漏收無補單；產品內取消不停綠界合約；已有訂閱又收到第二筆付款（建單 409／webhook 只記 log）；內容照 Notion §7.4
- [ ] 每張卡 8 欄皆填，重新驗測條件為可勾選清單
- [ ] 文件寫明「缺『重新驗測條件』或該欄不是可勾選清單的卡，視為未完成處置」
- [ ] 文件寫明「8-2 驗出阻斷型問題（錯誤解鎖、重複加點、過期仍可用、已收款未交付、無法追查）時，該卡排在預填卡之前」
- [ ] 卡末列人工接手白名單（查詢、註記、暫停入口、管理者補點 API）與禁止項（未驗簽／failed 改 paid、直接改餘額、手改期末）

**測試策略**：Test-After  
> 理由：純文件交付，以清單核對欄位與規則句即可。
