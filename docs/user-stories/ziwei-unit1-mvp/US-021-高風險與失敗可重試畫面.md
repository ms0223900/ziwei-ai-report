# US-021：高風險與失敗可重試畫面

**作為** 訪客  
**我想要** 失敗或高風險時看到繁中說明並可再送出  
**以便** 失敗不會被標成已解鎖，畫面也不會整頁崩潰

**輸入格式**：
- 200 + `error_code=HIGH_RISK` → 只顯示該類固定句 + disclaimer，無 CTA、無命盤
- 400／422／502／503 → 顯示 API `message`（或 design brief 失敗標題）
- 生成中文案：**正在整理你的基本分析…**；送出期間不可重複送
- 失敗主按鈕：再試一次；次：回表單

**輸出格式**：
- 表單／結果狀態元件（可放在 `BirthForm` 或獨立狀態視圖）
- 保留已填值；禁止只靠 `res.ok` 渲染報告卡

**驗收條件**：
- [ ] 高風險不渲染畫面 A、無解鎖 CTA
- [ ] 422／502／503 可再送出；不標記已解鎖
- [ ] 4xx／5xx／HIGH_RISK 無 uncaught／白屏
- [ ] 生成中按鈕 loading
- [ ] schema 失敗可重試的「改回 `MOCK_AI_MODE=valid`」註明在本機切 env（無控制台 UI）

**測試策略**：Test-After
> 理由：狀態畫面與文案以 design brief 為準；API 分支已由 US-017 鎖住。

**優先級**：P0  
**相關功能**：Story 4／5
