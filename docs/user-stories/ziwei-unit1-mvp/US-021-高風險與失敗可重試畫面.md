# US-021：高風險與失敗可重試畫面

**作為** 訪客  
**我想要** 失敗或高風險時看到繁中說明並可再送出  
**以便** 失敗不會被標成已解鎖，畫面也不會整頁崩潰

**輸入格式**：
- 200 + `error_code=HIGH_RISK` → 安全畫面（H1 + 該類固定句 + disclaimer + 回表單）；無解鎖 CTA、無命盤、不渲染畫面 A
- 400／422／502／503 → Hint 顯示 API `message`；H1／按鈕對齊 `.pen`
- 視覺主稿：[`designs/ziwei-unit1.pen`](../../../designs/ziwei-unit1.pen)
  - `Desktop / 03 生成中`、`Mobile / 03 生成中`
  - `Desktop / 06 生成失敗`、`Mobile / 06 生成失敗`
  - `Desktop / 07 高風險`、`Mobile / 07 高風險`
  - `Note / 其餘高風險固定句`（健康／法律／孕產／自傷；示範 frame 是財務句；**不另開畫面**）
- 對稿圖：`desktop-03-generating.png`、`desktop-06-fail.png`、`desktop-07-high-risk.png`、`mobile-03-generating.png`、`mobile-06-fail.png`、`mobile-07-high-risk.png`
- 畫布：desktop **1440**、mobile **390**；箋寬 576
- **層次（不要把 API 短句當成 H1）**：
  - 生成中 Lead：**正在依生辰起紫微命盤，定局排星中…**（跟 `.pen` 03，不要用 brief「正在整理你的基本分析…」）；印文 **排盤**；主鈕 `Button/PrimaryDisabled`／loading；送出期間不可重複送
  - 失敗 H1：**這次沒有寫成報告，你可以再試一次。**；Hint = API message（502 示範「生成失敗，請再試一次。」）；主鈕 **再試一次**、次鈕 **回表單**
  - 高風險 H1：**這題我不能用命盤作答**；正文 = 該類固定句（財務示範與 Note 四類，文案跟 spec／US-008）；**回表單**；無解鎖 CTA
  - spec「只顯示 message + disclaimer」= 不要畫面 A／不要命盤／不要解鎖；**允許** `.pen` 的 H1 與回表單

**輸出格式**：
- 表單／結果狀態元件（可放在 `BirthForm` 或獨立狀態視圖）
- 保留已填值；禁止只靠 `res.ok` 渲染報告卡

**驗收條件**：
- [ ] 生成中／失敗／高風險版面對齊 `.pen` 03／06／07；desktop 1440 與 mobile 390 都過
- [ ] 生成中 Lead 為「正在依生辰起紫微命盤，定局排星中…」
- [ ] 失敗畫面 H1 為長句、Hint 為 API `message`，兩者都在，不要只顯示其中一句
- [ ] 高風險：同一套 07 版面，只換正文固定句（Note：不另開五個畫面）；財務示範 + 其餘四類可切換；文案跟 spec
- [ ] 高風險有 H1「這題我不能用命盤作答」、disclaimer、回表單；不渲染畫面 A、無解鎖 CTA
- [ ] 422／502／503 可再送出；不標記已解鎖
- [ ] 4xx／5xx／HIGH_RISK 無 uncaught／白屏
- [ ] 生成中按鈕 loading、不可連點
- [ ] schema 失敗可重試的「改回 `MOCK_AI_MODE=valid`」註明在本機切 env（無控制台 UI）

**測試策略**：Test-After
> 理由：狀態畫面以 Pencil 對稿為準；API 分支已由 US-017 鎖住。
