# US-021：高風險與失敗可重試畫面

**作為** 訪客  
**我想要** 失敗或高風險時看到繁中說明並可再送出  
**以便** 失敗不會被標成已解鎖，畫面也不會整頁崩潰

**輸入格式**：
- 200 + `error_code=HIGH_RISK` → `.pen` 07：H1 + US-008 該類正文 + disclaimer + 回表單；無解鎖、無 ChartMatrix、不渲染畫面 A
- 422／502／503 → `.pen` 06：H1 長句 + Hint = API `message`
- 欄位驗證／HTTP 400 → `.pen` 02（US-019），**不是** 06
- 視覺主稿：`Desktop / 03 生成中`、`06 生成失敗`、`07 高風險` 與對應 Mobile；`Note / 其餘高風險固定句`
- 對稿圖：`desktop-03-generating.png`、`desktop-06-fail.png`、`desktop-07-high-risk.png`、`mobile-03-generating.png`、`mobile-06-fail.png`、`mobile-07-high-risk.png`
- 畫布：desktop **1440**、mobile **390**；箋寬 desktop **576**、mobile **350**
- 生成中 Lead：**正在依生辰起紫微命盤，定局排星中…**；印文 **排盤**；`Button/PrimaryDisabled`；不可連點
- 失敗 H1：**這次沒有寫成報告，你可以再試一次。**；Hint = API message；**再試一次**／**回表單**
- 高風險 H1：**這題我不能用命盤作答**；正文 = US-008 五類之一（財務示範；其餘四類同一 07 骨架只換正文，不另開畫面、不做切換器）

**輸出格式**：
- 表單／結果狀態元件
- 保留已填值；禁止只靠 `res.ok` 渲染報告卡

**驗收條件**：
- [x] 03／06／07 對齊 `.pen`；desktop 1440／箋 576 與 mobile 390／箋 350
- [x] 生成中 Lead 為「正在依生辰起紫微命盤，定局排星中…」
- [x] 失敗：H1 長句與 Hint API 短句都在
- [x] 06 不用來顯示欄位驗證錯誤
- [x] 高風險：同一 07，用五類暱稱各打一次只換正文；文案跟 US-008
- [x] 高風險有 H1、disclaimer、回表單；無畫面 A、無解鎖 CTA
- [x] 422／502／503 可再送出；不標記已解鎖
- [x] 4xx／5xx／HIGH_RISK 無白屏；HIGH_RISK 即使 HTTP 200 也不畫畫面 A（行為驗收，不只對稿）
- [x] 生成中不可連點
- [x] schema 失敗重試靠本機改 `MOCK_AI_MODE=valid`（無控制台 UI）

#### 驗收說明

**整體結論**：PASS ✅

> 表單送出改打 `POST /api/reports`，用 `error_code` 分流而不是 `res.ok`。本環境缺 service-role key，合法生辰走 503 失敗可重試；高風險暱稱走 07。瀏覽器 1440／390 已走 06／07；生成中有 500ms 下限，對稿非逐像素。

**AC-1：03／06／07 箋寬 576／350**

狀態：✅ 通過

- `BirthForm`／`FailSheet`／`HighRiskSheet` 皆 `max-w-[350px] md:max-w-[576px]`
- 瀏覽器 desktop 1440 與 mobile 390 已看到 06／07 箋本

---

**AC-2：生成中 Lead**

狀態：✅ 通過

- `BirthForm` `busy` 時 Lead 為「正在依生辰起紫微命盤，定局排星中…」，印文「排盤」
- `HomeClient` 的 `holdGenerating()` 至少顯示 500ms

---

**AC-3：失敗 H1 與 Hint**

狀態：✅ 通過

- `FailSheet` H1 固定長句；Hint 用 API `message`（live 503 為「儲存失敗，請再試一次。」）

---

**AC-4：欄位驗證不走 06**

狀態：✅ 通過

- 空暱稱仍在表單顯示「請填寫暱稱。」且不 `fetch`；`interpretReportsResponse` 把 400／`VALIDATION_ERROR` 判成 `validation`

---

**AC-5：五類高風險同一 07**

狀態：✅ 通過

- `HomeClient.test.tsx` 五類暱稱只換 `HIGH_RISK_MESSAGES` 正文；瀏覽器已打財務／健康／法律／孕產／自傷

---

**AC-6：高風險無畫面 A、無解鎖**

狀態：✅ 通過

- 200 + `HIGH_RISK` 渲染 `HighRiskSheet`；測試斷言無「的基本分析」、無 ChartMatrix、無「解鎖完整報告」

---

**AC-7：422／502／503 可重試**

狀態：✅ 通過

- 三個 HTTP 都進 `FailSheet`；「再試一次」重送 `lastBody`；不出現解鎖提示

---

**AC-8：HIGH_RISK 即使 200 不畫畫面 A**

狀態：✅ 通過

- `interpretReportsResponse` 先看 `error_code === "HIGH_RISK"`；mutation 改成當 report 後測試紅燈已還原

---

**AC-9：生成中不可連點**

狀態：✅ 通過

- `busy` 時 submit `disabled`，`handleSubmit` 直接 return；測試期間 `fetch` 只呼叫一次

---

**AC-10：schema 失敗無控制台 UI**

狀態：✅ 通過

- 422 走 06；「再試一次」再 POST。沒有切 `MOCK_AI_MODE` 的畫面控制，需本機改環境後重試
