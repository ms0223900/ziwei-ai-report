# US-019：生辰表單畫面

**作為** 訪客  
**我想要** 在公開頁填暱稱與生日（時辰、聚焦可空）  
**以便** 只在資料合法時開始生成

**輸入格式**：
- 視覺主稿：[`designs/ziwei-unit1.pen`](../../../designs/ziwei-unit1.pen) frame `Desktop / 01 生辰表單`、`Desktop / 02 表單驗證錯誤`；`Mobile / 01 生辰表單`、`Mobile / 02 表單驗證錯誤`
- 對稿圖（語意檔名；略過 `MeMfL.png` 等 frame-id 雜湊檔）：`designs/ziwei-unit1-previews/desktop-01-birth-form.png`、`desktop-02-form-error.png`、`mobile-01-birth-form.png`、`mobile-02-form-error.png`
- 畫布：desktop **1440**、mobile **390**；箋 `Sheet` 寬 desktop **576**（`$sheet-max`）；標題字 `$font-heading`（Noto Serif TC）
- 元件：`.pen` 的 `Button/Primary`、`Field/Default`、`Field/Error`、`Field/Select`、`FocusSegment`、`Disclaimer`（變數 `$paper`／`$sheet`／`$ink`／`$seal`／`$warn` 對 tokens.json 同名 key）
- **畫面上的標籤跟 `.pen` 實例，不是 brief ASCII、也不是元件庫預設「暱稱」**：
  - 產品名 **紫微解讀**；印文 **起盤**
  - Lead：**依生辰起紫微原局，先批基本命理。進階詳批封存。**
  - 欄位：`命主暱稱`（必填）、`生辰公曆（國曆）`（必填）、`出生時辰（選填）`
  - 時辰顯示值：**不確定時辰（走未知時辰盤）**；Hint：**未填時辰走未知時辰盤，準確度較低；知曉生時請選十二時辰（如卯時 05-07）。**
  - 聚焦標籤：**問事宮位（排盤焦點）**；三段 **整體・命身**／**工作・官祿**／**關係・夫妻**（請求仍只送 `整體`／`工作`／`關係`）
  - 主按鈕：**看基本分析**
- 錯誤句（欄位下、不用 toast）跟 spec／brief，且與 `.pen` 02 一致：**請填寫暱稱。**／**請填寫生日。**／格式／未來日
- 規則：生日 `YYYY-MM-DD` 上限今天；無性別／出生地欄

**輸出格式**：
- `components/birth-form/BirthForm.tsx`（client）
- 送出 body：`birth_time` 為 `null`（UI「不確定時辰…」不送該字串）；未選聚焦時省略 `focus` 或送空（不得送「感情」等非法值）；後端視為 `整體`

**驗收條件**：
- [ ] 版面（單欄箋本、欄位順序、必填標記、聚焦三段、無導覽列）對齊 `.pen` 01／02；desktop 1440 與 mobile 390 都過，不是只抄 brief ASCII
- [ ] 可見標籤／Lead／時辰 Hint／聚焦三段用上方 `.pen` 字，不要寫成「暱稱／時辰／整體」短標
- [ ] 有 disclaimer 完整句（文案跟 US-008／spec／`.pen` Disclaimer，三者同句）
- [ ] 前端先擋空白／非法生日；不呼叫模型（無 POST 或 POST 前 return）
- [ ] 時辰選「不確定時辰（走未知時辰盤）」或空白 → 請求 `birth_time: null`
- [ ] 聚焦三段對應 API `整體`／`工作`／`關係`，不可自填其他主題
- [ ] 未選聚焦時請求省略 `focus` 或為空；成功路徑不得把 `focus` 當成非法字串送出（`整體` 預設由後端 US-018 驗收）
- [ ] 無痕可用（不依賴 `localStorage` 才能填）
- [ ] 禁止紫漸層／英文主按鈕／brief 禁用清單

**測試策略**：Test-After
> 理由：對齊 Pencil 畫板與語意 preview，視覺回饋比預先寫 DOM 斷言有效。
