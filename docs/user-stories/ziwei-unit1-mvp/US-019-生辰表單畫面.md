# US-019：生辰表單畫面

**作為** 訪客  
**我想要** 在公開頁填暱稱與生日（時辰、聚焦可空）  
**以便** 只在資料合法時開始生成

**輸入格式**：
- 視覺主稿：[`designs/ziwei-unit1.pen`](../../../designs/ziwei-unit1.pen) frame `Desktop / 01 生辰表單`、`Desktop / 02 表單驗證錯誤`；`Mobile / 01 生辰表單`、`Mobile / 02 表單驗證錯誤`
- 對稿圖：`designs/ziwei-unit1-previews/desktop-01-birth-form.png`、`desktop-02-form-error.png`、`mobile-01-birth-form.png`、`mobile-02-form-error.png`
- 元件：`.pen` 的 `Button/Primary`、`Field/Default`、`Field/Error`、`Field/Select`、`FocusSegment`、`Disclaimer`（token `$paper`／`$sheet`／`$ink`／`$seal`／`$warn`）
- 產品規則：[`docs/design-brief.md`](../../design-brief.md) 畫面 1；欄位與錯誤句仍跟 AI spec／brief（暱稱、生日 `YYYY-MM-DD` 上限今天、時辰「不確定」、聚焦整體／工作／關係）
- 主按鈕文案：**看基本分析**；產品名 **紫微解讀**

**輸出格式**：
- `components/birth-form/BirthForm.tsx`（client）
- 送出 body：`birth_time` 為 `null`（UI「不確定」不送該字串）；未選聚焦時省略 `focus` 或送空（不得送「感情」等非法值）；後端視為 `整體`
- 欄位下錯誤文案（不用 toast）：請填寫暱稱／請填寫生日／格式／未來日

**驗收條件**：
- [ ] 版面（單欄箋本、欄位順序、必填標記、聚焦三段、無導覽列）對齊 `.pen` 01／02 的 desktop 與 mobile，不是只抄 brief ASCII
- [ ] 有 disclaimer 完整句（文案跟 US-008／spec）
- [ ] 前端先擋空白／非法生日；不呼叫模型（無 POST 或 POST 前 return）
- [ ] 時辰「不確定」或空白 → 請求 `birth_time: null`
- [ ] 聚焦不可自填其他主題
- [ ] 未選聚焦時請求省略 `focus` 或為空；成功路徑不得把 `focus` 當成非法字串送出（`整體` 預設由後端 US-018 驗收）
- [ ] 無痕可用（不依賴 `localStorage` 才能填）
- [ ] 禁止紫漸層／英文主按鈕／brief 禁用清單

**測試策略**：Test-After
> 理由：對齊 Pencil 畫板與 preview，視覺回饋比預先寫 DOM 斷言有效。

**優先級**：P0  
**相關功能**：Story 1；Checkpoint A5  
**依賴關係**：US-001、US-008
