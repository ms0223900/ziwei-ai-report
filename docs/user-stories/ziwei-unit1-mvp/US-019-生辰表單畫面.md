# US-019：生辰表單畫面

**作為** 訪客  
**我想要** 在公開頁填暱稱與生日（時辰、聚焦可空）  
**以便** 只在資料合法時開始生成

**輸入格式**：
- 視覺主稿：[`designs/ziwei-unit1.pen`](../../../designs/ziwei-unit1.pen) `Desktop / 01 生辰表單`、`Desktop / 02 表單驗證錯誤`；`Mobile / 01 生辰表單`、`Mobile / 02 表單驗證錯誤`
- 對稿圖：`designs/ziwei-unit1-previews/desktop-01-birth-form.png`、`desktop-02-form-error.png`、`mobile-01-birth-form.png`、`mobile-02-form-error.png`（略過 frame-id 雜湊檔）
- 畫布：desktop **1440**、mobile **390**；箋寬 desktop **576**、mobile **350**；標題 `$font-heading` → tokens `fontFamily.heading`
- 畫面標籤跟 `.pen` 實例（元件庫預設「暱稱」必須覆寫）：
  - 產品名 **紫微解讀**；印文 **起盤**
  - Lead：**依生辰起紫微原局，先批基本命理。進階詳批封存。**
  - `命主暱稱`、`生辰公曆（國曆）`、`出生時辰（選填）`
  - 時辰關閉態：**不確定時辰（走未知時辰盤）** → JSON `null`
  - 時辰選項：上述一項 + 十二支。顯示可為「卯時 05-07」；JSON **只送** `子`…`亥`
  - Hint：**未填時辰走未知時辰盤，準確度較低；知曉生時請選十二時辰（如卯時 05-07）。**
  - 聚焦：**問事宮位（排盤焦點）**；**整體・命身**／**工作・官祿**／**關係・夫妻** → 請求 `整體`／`工作`／`關係`
  - `01` 對稿預設選 **工作・官祿**（示範 POST `focus=工作`）。未選／省略 `focus` 是 API 行為，沒有獨立 frame
  - 主按鈕：**看基本分析**
- `02` 示範錯誤：**請填寫暱稱。**／**請填寫生日。** 格式／未來日用同一 `Field/Error`，brief 句不變，**沒有**對應 frame
- 生日上限今天；無性別／出生地欄

**輸出格式**：
- `components/birth-form/BirthForm.tsx`（client）
- 送出：`birth_time` 為 `null` 或單字時辰；未選聚焦時省略 `focus` 或送空；不得送「感情」或「卯時 05-07」

**驗收條件**：
- [ ] 版面對齊 `.pen` 01／02；desktop 1440／箋 576 與 mobile 390／箋 350 都過
- [ ] 可見標籤／Lead／Hint／三段用上方 `.pen` 字
- [ ] disclaimer 與 US-008／spec／`.pen` 同句
- [ ] 前端先擋空白／非法生日；走 02，不呼叫模型，不套 06 H1
- [ ] 「不確定時辰（走未知時辰盤）」或空白 → `birth_time: null`
- [ ] 選十二支時 JSON 為單字 `子`…`亥`
- [ ] 聚焦三段對應 API 三值；不可自填
- [ ] 無痕可用
- [ ] 禁止紫漸層／英文主按鈕／brief 禁用清單

**測試策略**：Test-After
> 理由：對齊 Pencil 畫板與語意 preview，視覺回饋比預先寫 DOM 斷言有效。
