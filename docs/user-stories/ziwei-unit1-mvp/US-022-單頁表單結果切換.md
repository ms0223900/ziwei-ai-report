# US-022：單頁表單結果切換

**作為** 訪客  
**我想要** 表單與結果在同一頁切換  
**以便** 無痕視窗一次跑完示範、不依賴 localStorage

**輸入格式**：
- `app/page.tsx` 單頁 wizard；接 US-019／US-020／US-021；`POST /api/reports`（US-018）
- 視覺主稿：Desktop／Mobile `01`–`07` 全名見 README
- 底 token `paper`；desktop 箋 576、mobile 箋 350；viewport 對稿 **1440** 與 **390**
- 對稿 14 張語意 PNG：`desktop-01-birth-form.png` … `desktop-07-high-risk.png`、`mobile-01-birth-form.png` … `mobile-07-high-risk.png`
- 結果放元件 state；重新整理 = 新的一次 POST
- 行為／安全跟 spec；可見字跟 `.pen`（與 brief／spec 同句）

**輸出格式**：
- 公開首頁：填 → 生成中 → 畫面 A 或高風險或失敗（含 02 驗證錯、05 CTA）
- token 用 `assets/design-tokens.json`／`app/globals.css`；`$font-heading` 接到 `--font-noto-serif-tc`／`font-serif`
