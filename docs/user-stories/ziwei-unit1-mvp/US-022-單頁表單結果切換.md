# US-022：單頁表單結果切換

**作為** 訪客  
**我想要** 表單與結果在同一頁切換  
**以便** 無痕視窗一次跑完示範、不依賴 localStorage

**輸入格式**：
- `app/page.tsx` 單頁 wizard
- 接 US-019／US-020／US-021
- `POST /api/reports`（US-018）
- 視覺主稿：[`designs/ziwei-unit1.pen`](../../../designs/ziwei-unit1.pen) 全部 Must 狀態（Desktop／Mobile `01`–`07` 全名見 README 表）
- 底為 `$paper`（CSS token `paper`）、箋 `Sheet` 寬 desktop 576；對稿 viewport：**desktop 1440** 與 **mobile 390** 各走一輪
- 對稿 PNG 用語意檔名（共 14 張）：
  `desktop-01-birth-form.png` … `desktop-07-high-risk.png`、
  `mobile-01-birth-form.png` … `mobile-07-high-risk.png`  
  不要用 `desktop-0{1-7}-*.png` glob（會誤配雜湊檔或漏檔）
- 結果只放元件 state；重新整理 = 新的一次 POST（本版接受）
- 衝突：行為／安全跟 AI spec；可見字與版面跟 `.pen`（規則見 README「畫面視覺來源」）

**輸出格式**：
- 公開首頁可走：填 → 生成中 → 畫面 A 或高風險或失敗（含表單驗證錯誤、CTA 點擊）
- token 用 `assets/design-tokens.json`／`app/globals.css`，不另造色票；`$font-heading` 接到 Noto Serif TC（既有 `--font-noto-serif-tc` 即可）

**驗收條件**：
- [ ] Mock valid 示範輸入可看到畫面 A，且 1440／390 對得上 `.pen` 04（含 ChartMatrix）
- [ ] 高風險暱稱走 `.pen` 07 安全畫面（同一版面換固定句，不另開頁）
- [ ] 前端驗證錯誤對齊 `.pen` 02，不發成功報告請求（或發了也只會 400）
- [ ] 生成中對齊 `.pen` 03 的 Lead 句
- [ ] 無 `localStorage` 也能完成填寫與看結果
- [ ] 無追問主流程；無假裝付款
- [ ] `npm run build`／`lint`／`typecheck` 盡可能通過

**測試策略**：Test-After
> 理由：跨畫面串接以 Pencil desktop 1440／mobile 390 對稿為主；邏輯門檻已在 API 測試。
