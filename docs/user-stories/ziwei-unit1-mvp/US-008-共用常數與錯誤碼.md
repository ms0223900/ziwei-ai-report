# US-008：共用常數與錯誤碼

**作為** 系統  
**我想要** disclaimer、locked_fields、錯誤碼與繁中訊息同一來源  
**以便** API 與畫面不各寫一套

**輸入格式**：
- disclaimer：`本結果僅供娛樂與自我反思，不作為醫療、法律、財務、投資或重大人生決策依據。`
- `locked_fields`：`["action_plan","path_compare","rationale"]`
- error_code：`VALIDATION_ERROR`／`SCHEMA_INVALID`／`GENERATION_FAILED`／`PERSIST_FAILED`／`HIGH_RISK` 與 AI spec 對應繁中 message

**輸出格式**：
- `lib/constants.ts`
- `lib/errors.ts`（可對應 HTTP status 的錯誤型別）

**驗收條件**：
- [ ] disclaimer 字串與 design brief 完整句一致（含「投資」）
- [ ] `locked_fields` 固定為進階三欄
- [ ] 422／502／503 預設 message 與 spec 表一致
- [ ] 本任務不實作 Route Handler

**測試策略**：Test-After
> 理由：常數對齊，無狀態轉換；後續 API／UI 測試會引用這些值。

**優先級**：P0  
**相關功能**：Story 3／5  
**依賴關係**：無
