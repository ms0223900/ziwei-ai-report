# US-005：生辰驗證規則實作

**作為** 系統  
**我想要** 前後端同一組生辰規則  
**以便** 無效資料不呼叫模型、不寫 DB

**輸入格式**：
- `{ nickname, birth_date, birth_time?, focus? }`
- 錯誤訊息對齊 brief／`.pen`：請填寫暱稱。／請填寫生日。／生日請用 YYYY-MM-DD，例如 1993-07-12。／生日不能是未來日期。
- 未來日比較用 `Asia/Taipei` 日曆日

**輸出格式**：
- `lib/validation/birth.ts`：成功回正規化物件；失敗回可對應 HTTP 400 的錯誤
- 正規化：`nickname` trim；未填時辰 → `birth_time=null`、`time_unknown=true`；空 focus → `整體`

- [x] 不在此任務寫入 `reports` 或呼叫 LLM
