# US-016：會員視圖第三態 測試

**作為** 開發者  
**我想要** 先有會失敗的視圖第三態測試  
**以便** 帳號 locked × 此報告已單點解鎖時進階可見、且不是終身 CTA

**輸入格式**：
- 擴充 `resolveMembershipView`（現況只有訪客／locked／終身 unlocked 二元）
- 建議新增輸入：`pointsBalance`、`unlockMode: "lifetime" | "points" | "none"`（名稱可同義）、是否自己的報告
- 終身：進階可見；隱藏終身解鎖主按鈕；**不**把狀態畫成單點解鎖
- 單點第三態：標題可為進階；`advancedLocked=false`；不顯示「用 1 點解鎖」；`access` 語意不是終身開通
- 自己的報告、none、餘額 ≥ 1：鎖定；顯示「用 1 點解鎖此報告」
- 自己的報告、none、餘額 < 1：鎖定；不足旗標（畫面出口交給 US-018）
- 已登入（含終身）：買點入口旗標為可見
- 無 session：不顯示單點解鎖；買點／終身皆走登入
- `profiles.points_balance` 由 US-018 從 `app/page.tsx` 傳入；本任務只測純函式輸入 `pointsBalance`

**輸出格式**：
- 對應 `*.test.ts`（建議擴充 `lib/membership/view.test.ts`）
