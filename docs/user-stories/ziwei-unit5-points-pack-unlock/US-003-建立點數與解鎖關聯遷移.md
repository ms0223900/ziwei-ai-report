# US-003：建立點數與解鎖關聯遷移

**作為** 系統  
**我想要** 最小 migration：帳本、單點解鎖關聯、`reports.user_id`  
**以便** 加點／扣點可追查，且 Client 不能改權益

**輸入格式**：
- spec §4：`point_transactions`、`report_unlocks`、`reports.user_id uuid null`
- credit：`delta=+5`、`type=credit_purchase`、`source_order_id` 必填且 **unique**（FK `orders.id`）
- debit：`delta=-1`、`type=debit_unlock`、`report_id` 必填（FK `reports.id`）
- `report_unlocks` PK／unique `(user_id, report_id)`；`transaction_id` 對應 debit
- RLS：authenticated 可 SELECT 自身帳本／解鎖列；INSERT／UPDATE／DELETE 僅 service role
- 延續 `profiles_guard_entitlements`；Client 不可 UPDATE `reports.user_id`／`points_balance`
- **不加** `orders.fulfilled_at`；**不改** `access_status` 語意
- 實作應加 credit 的 `source_order_id` NOT NULL CHECK（或等價），避免無訂單 credit

**輸出格式**：
- `supabase/migrations/` 新時間戳 SQL（勿用 architecture 佔位名硬撞）
- 本任務只交付可套用 SQL；未套用成功前，不得把 US-009／US-013 加點／扣點 AC 勾成完成

**驗收條件**：
- [x] 表欄位對齊 spec：帳本、解鎖關聯、`reports.user_id`
- [x] credit `source_order_id` unique；解鎖列 `(user_id, report_id)` unique
- [x] RLS on；會員可讀自身、不可寫帳本／解鎖／`reports.user_id`
- [x] `profiles` 無新欄位；`orders` 無 `fulfilled_at`
- [x] Client SDK `update points_balance`／insert 帳本或解鎖關聯／`update reports.user_id` 失敗（Story 12）
