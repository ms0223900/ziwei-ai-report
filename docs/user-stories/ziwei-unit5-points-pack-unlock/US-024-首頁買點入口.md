# US-024：首頁買點入口

**作為** 已登入會員  
**我想要** 在首頁（還沒產生報告前）就能看到點數餘額並購買點數包  
**以便** 不必先產生一份報告才找得到買點入口

**輸入格式**：
- SSR `initialPointsBalance`（US-018 已由 `app/page.tsx` 傳入 `HomeClient`）
- 買點沿用 `UnlockCheckoutCta`：只送 `{ "plan_id": "points_pack_5" }`；不另寫付款流程
- 位置：首頁生辰表單畫面上方的一列；報告畫面維持 US-018 的報告區買點，不重複顯示
- 槽位 `slot-home-points-pack`

**輸出格式**：
- `components/home/HomePointsBar.tsx`（或等價）＋接到 `HomeClient` 表單畫面
- 文案：「目前點數：N 點」＋「購買點數包」

**驗收條件**：
- [ ] 已登入時，首頁表單畫面顯示點數餘額與「購買點數包」
- [ ] 點「購買點數包」送 `POST /api/payments/checkout` `{ "plan_id": "points_pack_5" }`
- [ ] 訪客首頁不顯示這一列
- [ ] 報告畫面不重複出現這一列（報告區買點不變）
- [ ] 餘額只來自 SSR `profiles.points_balance`：付款回到 `/` 重新載入後顯示新餘額；前端不自行加點

**測試策略**：Test-After  
> 理由：顯示條件與送出內容單純，入口排版以畫面回饋為主；互動以 `HomeClient.test.tsx` 補測。

**優先級**：P1  
**相關功能**：Story 3（已開通不隱藏買點）；US-018 延伸  
**依賴關係**：US-007、US-018
