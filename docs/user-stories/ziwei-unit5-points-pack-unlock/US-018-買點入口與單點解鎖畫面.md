# US-018：買點入口與單點解鎖畫面

**作為** 已登入會員  
**我想要** 報告區看到「購買點數包」與「用 1 點解鎖此報告」  
**以便** 已永久解鎖仍能示範點數制，未解鎖報告可用 1 點開啟

**輸入格式**：
- US-017 視圖旗標；US-007 建單 `points_pack_5`；US-013 解鎖 API
- 終身 CTA 與點數包 CTA **必須分開**；買點不得複用 `UnlockCheckoutCta` 寫死的 `unlock_report_lifetime`
- 買點 JSON 只送 `{ "plan_id": "points_pack_5" }`（字串可來自無 secret 的 plan id 常數，或寫死同一字串）
- 單點 JSON 欄位名可叫 `report_id`，**值必須等於** GET／POST 的 `persist_id`（`reports.id`）；**禁止**送 GET body 的 `report_id`（`basic_json.report_id`，例如 `rpt_demo_001`）
- 建議文案「購買點數包」；建議槽位 `slot-points-pack-cta`／`slot-unlock-with-point`
- `unlocked`：隱藏終身主按鈕；**不隱藏**買點
- `locked` 且已登入：終身 CTA 與買點都可見
- 訪客點買點或單點：請先登入彈窗、不發建單／不扣點
- 自己的未解鎖報告且餘額 ≥ 1：顯示「用 1 點解鎖此報告」；成功後走 GET（即使帳號 locked）
- `reason=insufficient`：最小提示＋購買點數包／返回報告
- `HomeClient`：單點成功後即使 `accessStatus !== "unlocked"` 仍 GET 該 `persist_id`
- 主路徑禁止再出現單元 2「點數只買追問、不解鎖報告」（`MODE_CREDIT_LINE`／`FOLLOWUP_HINT`）

**輸出格式**：
- `app/page.tsx`：把 `ensureProfile().points_balance` 傳進 `HomeClient`（例如 `initialPointsBalance`），供 US-016 旗標使用
- `components/report/` CTA／鎖定面板、`components/home/HomeClient.tsx`（擁有 `loadAdvanced`：即使 `accessStatus !== "unlocked"` 仍 GET 自己的 `persist_id`）、`lib/constants.ts` 文案
- 買點送 `{ plan_id: "points_pack_5" }`；單點送 `{ report_id: persist_id }`（值＝`reports.id`）

**驗收條件**：
- [x] 已開通畫面有買點、無終身解鎖主按鈕
- [x] locked 已登入可見終身 CTA 與買點
- [x] 訪客點買點不發 checkout
- [x] 自己的報告可點「用 1 點解鎖此報告」；不足時有購買／返回、不顯示已開通
- [x] SSR `points_balance` 進 view，鎖定區能在點擊前分辨 ≥ 1／不足
- [x] 單點成功後重整前即可 GET 進階（不依賴把帳號畫成終身；須 US-015 擁有者 GET 已綠）
- [x] 主路徑無「點數不解鎖報告」舊句
