# US-021：已單次解鎖選單畫面

**作為** 已用點解鎖過報告的會員  
**我想要** 導覽或報告區的簡單選單  
**以便** 重整或重登後仍能開啟那些報告的進階

**輸入格式**：
- US-020 選單 API；US-015 進階 GET；US-018 已改的 `HomeClient.loadAdvanced`（選單點選不得另寫一套終身-only 閘門）
- 位置：簡單選單，不是獨立產品頁、不是篩選器
- 項目至少能打開對應 `persist_id` 的進階
- 建議槽位 `slot-report-unlocks`

**輸出格式**：
- 選單元件（導覽或報告區）＋接上 `HomeClient` GET

**驗收條件**：
- [ ] 選單含已單點解鎖的報告；點選後可再開進階
- [ ] 終身開通時選單不倒入全部 `reports`
- [ ] 未綁 `user_id` 的舊列不出現
- [ ] 重整／重登後仍在（讀 API，不靠記憶體）

**測試策略**：Test-After  
> 理由：選單排版以畫面為主；資料契約已由 US-019／US-020 鎖住。

**優先級**：P0  
**相關功能**：Story 10  
**依賴關係**：US-015、US-018、US-020
