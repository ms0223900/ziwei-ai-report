# US-018：首頁訂閱接線與月繳入口

**作為** 有效訂閱會員  
**我想要** 重整或重登後新產生的報告直接顯示進階，未訂閱的人看得到月繳入口  
**以便** 訂閱權益在畫面上真的生效

**輸入格式**：
- US-009、US-015、US-017 已完成
- `app/page.tsx`、`components/home/HomeClient.tsx`、`components/report/AdvancedLockedPanel.tsx`、`UnlockWithPointCta.tsx`

**輸出格式**：
- 上述檔案
- 對應 RTL 測試（擴充 `HomeClient.test.tsx`、`AdvancedLockedPanel.test.tsx`）

**驗收條件**：
- [ ] `app/page.tsx` 在 server 端查出 `subscriptionActiveUntil`（期間未過才有值）並傳給 `HomeClient`
- [ ] `loadAdvanced` 閘門加上 `subscriptionActive`；`resolveMembershipView` 傳入 `hasActiveSubscription`
- [ ] S7-3：重整或重登後**新產生**的報告顯示真實進階與「訂閱有效至 …」，不顯示用點解鎖、終身 CTA 或月繳 CTA（舊報告重開不在範圍，PM 已定案）
- [ ] S7-7：進階 GET 回 403 時退回鎖定分支，顯示 CTA 與繁中提示，不卡在空白佔位
- [ ] `AdvancedLockedPanel` 新增月繳 CTA（`planId="subscribe_report_monthly"`，client 常數）；已永久解鎖者也顯示；訂閱有效時隱藏
- [ ] `UnlockWithPointCta` 的 `OK_REASONS` 加入 `subscription`；`reason=subscription` 時設 `subscriptionActive`，**不**呼叫 `setPointUnlocked(true)`（S8-1 不顯示「已用 1 點解鎖」）
- [ ] `npm run lint`／`typecheck`／既有測試全綠

**測試策略**：Test-After  
> 理由：UI 接線以 RTL 驗主要狀態，其餘靠瀏覽器確認，視覺回饋比先寫斷言有效率。

**優先級**：P0  
**相關功能**：Story 1／7／8；spec 第 7 節阻塞 3（已定案）  
**依賴關係**：US-009、US-015、US-017
