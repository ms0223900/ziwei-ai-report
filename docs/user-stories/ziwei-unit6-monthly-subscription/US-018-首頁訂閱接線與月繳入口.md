# US-018：首頁訂閱接線與月繳入口

**作為** 有效訂閱會員  
**我想要** 重整或重新登入後，新產生的報告直接顯示進階內容；未訂閱的人看得到月繳入口  
**以便** 訂閱權益在畫面上真正生效

**輸入格式**：
- US-009、US-015、US-017 已完成
- `app/page.tsx`、`components/home/HomeClient.tsx`、`components/report/ReportCard.tsx`、`AdvancedLockedPanel.tsx`、`UnlockWithPointCta.tsx`

**輸出格式**：
- 上述檔案
- 對應的 RTL 測試（擴充 `HomeClient.test.tsx`、`AdvancedLockedPanel.test.tsx`）

**驗收條件**：
- [ ] `app/page.tsx` 用**獨立的** try/catch 查 `subscriptionActiveUntil`（期間未過才有值）；查詢失敗（例如表還沒套用）時設為 null，**不影響** `access_status` 與點數
- [ ] `loadAdvanced` 的閘門加入 `subscriptionActive`；呼叫 `resolveMembershipView` 時傳入 `hasActiveSubscription` 與 `subscriptionActiveUntil`
- [ ] S7-3：重整或重新登入後**新產生**的報告，顯示真實進階內容與「訂閱有效至 …」，且不顯示「用點解鎖」、終身 CTA、月繳 CTA（舊報告重開不在範圍內，PM 已定案）
- [ ] S7-7：`fetchAdvancedBody` 要區分 403 與其他錯誤；遇到 403 時把 `subscriptionActive` 設為 false，退回鎖定分支，並顯示「訂閱已失效，請重新整理」
- [ ] `AdvancedLockedPanel` 新增月繳 CTA（`planId="subscribe_report_monthly"`，使用 client 常數）；已永久解鎖者也顯示；訂閱有效時隱藏
- [ ] `UnlockWithPointCta` 的 `OK_REASONS` 加入 `subscription`；`onUnlocked` 的回呼改為同時帶 `reason`，並經 `ReportCard`／`AdvancedLockedPanel` 往上傳到 `HomeClient`
- [ ] `reason=subscription` 時設定 `subscriptionActive`，**不要** `setPointUnlocked(true)`（S8-1：不顯示「已用 1 點解鎖」）
- [ ] `npm run lint`、`npm run typecheck` 與既有測試全綠

**測試策略**：Test-After  
> 理由：UI 接線以 RTL 驗主要狀態，其餘靠瀏覽器確認；視覺回饋比先寫斷言有效率。

**優先級**：P0  
**相關功能**：Story 1／7／8；spec 第 7 節阻塞 3（已定案）  
**依賴關係**：US-009、US-015、US-017
