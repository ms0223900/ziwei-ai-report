# US-023：通知頁面

**作為** 已登入會員  
**我想要** 一個最小的通知列表頁  
**以便** 看到每則通知並標記已讀

**輸入格式**：
- US-022 的兩支 API；spec §2 Story 5（`/notifications`）

**輸出格式**：
- `app/notifications/page.tsx`；頁首加一個通往 `/notifications` 的入口（僅登入時顯示）

**驗收條件**：
- [ ] 列出每則的 `text`、建立時間、已讀狀態；點擊前往 `href`
- [ ] 未讀列有「標為已讀」按鈕；按下後呼叫 POST，該列顯示已讀
- [ ] 未登入顯示「請先登入」，不列任何通知
- [ ] 沒有通知時顯示可讀的繁中空狀態
- [ ] API 失敗時顯示可讀繁中提示，不整頁 crash

**測試策略**：Test-After  
> 理由：列表排版與互動以畫面回饋為主，API 邏輯已由 US-021／022 鎖住。

**優先級**：P0  
**相關功能**：Story 5  
**來源**：Story 5（§2 頁面 `/notifications`）  
**依賴關係**：US-022
