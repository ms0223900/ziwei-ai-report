# US-026：管理者查詢頁

**作為** 白名單管理者  
**我想要** 用訂單 id 查這一筆的狀態、證據與處置原因，並送出補點  
**以便** 分辨「已付款但未交付」與「已交付」

**輸入格式**：
- US-025 的 `is-admin`、`derive-order-reason`、補償 API；spec §2 Story 6 頁面段

**輸出格式**：
- `app/admin/orders/page.tsx`（RSC，service role 讀取）與一個補點表單（`reason` 必填）

**驗收條件**：
- [x] S6-4：未登入顯示「請先登入」；非白名單顯示「沒有管理權限」（HTTP 403），兩者都不讀訂單或餘額
- [x] 顯示：訂單 status、plan、amount；credit／`access_status`／`first_success`＋`current_period_end` 是否存在；對應成功通知是否存在；`derive-order-reason` 的結果
- [x] 補點表單送出後顯示 API 的 `result`（`ok`／`skipped_already_fulfilled`／錯誤訊息）
- [x] 缺 `order` 或查無訂單時顯示可讀繁中提示
