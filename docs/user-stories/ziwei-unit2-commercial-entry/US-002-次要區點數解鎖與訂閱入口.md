# US-002：次要區點數解鎖與訂閱入口

**作為** 訪客  
**我想要** 在主 CTA 下方看到鎖定的「用 1 點解鎖」按鈕與訂閱入口  
**以便** 知道點數是用 1 點解鎖 1 份報告、訂閱在有效期間內可看進階，且兩者都尚未開放

**輸入格式**：
- 槽位：`slot-point-unlock`、`slot-subscribe`（常數來自 US-001）
- 點數：鎖定按鈕「用 1 點解鎖」，旁白「即將開放」；說明「用 1 點解鎖這 1 份報告；不重算命盤，也不等於永久解鎖」
- 訂閱：次要按鈕或文字鏈「了解訂閱權益」；說明「訂閱有效期間內可看進階報告；第一版不做月報」
- 三種模式各一句：單次解鎖看進階不附贈點數；點數用 1 點解鎖 1 份報告；訂閱有效期間內可看進階
- 即將開放文案與主 CTA 同款：「解鎖即將開放，本版不收費。」
- 鎖定按鈕：`aria-disabled`＋點擊處理，`type="button"`，禁止 `disabled`

**輸出格式**：
- 次要區元件（可放 `components/report/`）掛在主 CTA 下方
- 更新 `ReportCard.test.tsx`：畫面 A 可見鎖定的「用 1 點解鎖」按鈕；點它或訂閱入口不改標題、不呼叫 fetch

**驗收條件**：
- [x] 主 CTA 下方可見 `slot-point-unlock` 與 `slot-subscribe`，且不是與主 CTA 同等級的三個並列主按鈕
- [x] 「用 1 點解鎖」為鎖定態（`aria-disabled`、非 `disabled`），點擊顯示即將開放說明
- [x] 點「了解訂閱權益」顯示即將開放說明，不開結帳
- [x] 三種模式各一句產品狀態可見
- [x] 點擊不觸發 `fetch`／`requestReport`，標題仍為「{暱稱}的基本分析」
- [x] 本任務不實作預覽 B／C／D
