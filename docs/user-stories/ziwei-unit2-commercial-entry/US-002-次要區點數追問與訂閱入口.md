# US-002：次要區點數追問與訂閱入口

**作為** 訪客  
**我想要** 在主 CTA 下方看到鎖定追問框與訂閱入口  
**以便** 知道點數只買追問、訂閱看進階＋月額度，且兩者都尚未開放

**輸入格式**：
- 槽位：`slot-followup`、`slot-subscribe`（常數來自 US-001）
- 追問：`placeholder`「追問需點數或訂閱」；說明「點數只買 1 次追問；不解鎖報告、不重算命盤」
- 訂閱：次要按鈕或文字鏈「了解訂閱權益」；說明「訂閱有效可看進階報告，本月可追問 10 次；第一版不做月報」
- 三種模式各一句：單次解鎖看進階不附贈追問；點數只買 1 次追問；訂閱看進階＋本月追問 10 次
- 即將開放文案與主 CTA 同款：「解鎖即將開放，本版不收費。」
- 鎖定框：`readOnly`＋點擊／focus 處理，禁止 `disabled`

**輸出格式**：
- 次要區元件（可放 `components/report/`）掛在主 CTA 下方
- 更新 `ReportCard.test.tsx`：畫面 A 允許 readOnly 追問框；點追問／訂閱不改標題、不呼叫 fetch

**驗收條件**：
- [ ] 主 CTA 下方可見 `slot-followup` 與 `slot-subscribe`，且不是與主 CTA 同等級的三個並列主按鈕
- [ ] 追問框 `readOnly`、不可輸入，點擊或 focus 顯示即將開放說明
- [ ] 點「了解訂閱權益」顯示即將開放說明，不開結帳
- [ ] 三種模式各一句產品狀態可見
- [ ] 點擊不觸發 `fetch`／`requestReport`，標題仍為「{暱稱}的基本分析」
- [ ] 本任務不實作預覽 B／C／D

**測試策略**：Test-After
> 理由：次要區以文案層級與點擊提示為主，屬 UI 交互，補元件測試即可。
