# US-005：開發預覽條與四態畫面

**作為** 學員  
**我想要** 在開發預覽開啟時切 A／B／C／D  
**以便** 對照單元 4～6 的交付位置，且不寫入資料庫

**輸入格式**：
- US-004 純函式
- `NEXT_PUBLIC_COMMERCIAL_PREVIEW`：`1` 顯示預覽條；未設或 `0` 不顯示任何切換控件
- `ReportCard` optional `commercialPreviewEnabled?: boolean`；未傳時讀該公開 env
- `preview_state` 只存在 `ReportCard` 掛載的 `useState`，初值 `A`
- 預覽條文案：「開發預覽｜尚未實作真實付款」
- C／D 追問送出：「追問 API 尚未實作」；按鈕 `type="button"`，禁止 submit 重整

**輸出格式**：
- 預覽條元件（僅報告成功視圖內，勿掛在 `FailSheet`／`HighRiskSheet`）
- `.env.example` 留位 `NEXT_PUBLIC_COMMERCIAL_PREVIEW=0` 與註解
- `ReportCard` 依有效態改標題、鎖定／範例、CTA、追問、訂閱文案
- A／B／C／D 皆保留 disclaimer

**驗收條件**：
- [ ] `commercialPreviewEnabled=false`（或未設 env）時無預覽控件，畫面為 A
- [ ] `=true` 時頂部可見「開發預覽｜尚未實作真實付款」，可切 A／B／C／D
- [ ] 切換只改前端；元件內無 `fetch`、無 `localStorage`／`sessionStorage`
- [ ] 預覽 B：標題「{暱稱}的進階報告」；三區為「預覽用範例」；追問仍鎖定
- [ ] 預覽 C／D 送出追問顯示「追問 API 尚未實作」，不呼叫 `/api/reports`
- [ ] 預覽條不擋住 disclaimer 與鎖定區
- [ ] URL 帶 `?preview=B`（或 `tier`／`status`）仍渲染 A 的有效內容
- [ ] 不把預覽 B 當成「單次解鎖完成」驗收

**測試策略**：Test-After
> 理由：預覽條與四態是畫面組裝；狀態規則已由 US-003／US-004 鎖住。
