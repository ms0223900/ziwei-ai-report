# US-001：商業槽位與具名鎖定區

**作為** 學員  
**我想要** 報告頁鎖定區與主 CTA 有穩定槽位名  
**以便** 單元 4～6 能接線且驗收能指出免費／付費切線

**輸入格式**：
- 規格槽位：`slot-lock-action-plan`／`slot-lock-rationale`／`slot-lock-path-compare`／`slot-delivery`／`slot-unlock-cta`
- 既有畫面 A：`components/report/AdvancedLockedPanel.tsx`、`components/report/ReportCard.tsx`
- 屬性名：`data-report-slot`（取代隱藏的 `data-report-slot="advanced"`）
- `slot-delivery`：包住三個鎖定區的可見容器，不是獨立空白塊

**輸出格式**：
- `lib/constants.ts`（或同級）匯出槽位字串常數
- 鎖定三區與主 CTA 掛上對應 `data-report-slot`
- 更新 `components/report/ReportCard.test.tsx` 斷言槽位存在

**驗收條件**：
- [ ] 三鎖定區與主 CTA 的 `data-report-slot` 值與規格槽位名一致
- [ ] `slot-delivery` 包住三個鎖定區
- [ ] 鎖定區仍是封條「未開封」＋佔位灰條，不含 `rationale`／`path_a`／「第 1 天」
- [ ] 點「解鎖完整報告」仍只出現「解鎖即將開放，本版不收費。」，標題仍為基本分析
- [ ] 隱藏的 `data-report-slot="advanced"` 已移除
- [ ] 不改 `POST /api/reports`、不改 `buildReportResponse`

**測試策略**：Test-After
> 理由：在既有畫面 A 掛 `data-*` 與常數，DOM 斷言比預先寫失敗測試有效。

**優先級**：P0  
**相關功能**：Story 1／2；spec 第 7 節問題 3  
**依賴關係**：無
