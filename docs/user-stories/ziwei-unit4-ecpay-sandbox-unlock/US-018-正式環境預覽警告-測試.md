# US-018：正式環境預覽警告 測試

**作為** 開發者  
**我想要** 先有會失敗的 production 預覽守衛測試  
**以便** live 不會把單元 2 假文當成已付款

**輸入格式**：
- `NODE_ENV === "production"` 且 `NEXT_PUBLIC_COMMERCIAL_PREVIEW=1` → `role="alert"`：「設定錯誤：正式環境不應開啟開發預覽。此畫面不是已付款開通。」且無 overlay／EXAMPLE_BLOCKS／四態切換
- production 且預覽不是 `1`：無預覽條、無警告
- 非 production 且預覽 `1`：允許 unit2 overlay，不要求本警告
- 誤設＋locked／訪客：鎖定占位；誤設＋unlocked：GET 真文與警告並存
- 禁止 query 在正式環境切 B／C／D

**輸出格式**：
- 對應 `*.test.ts`（preview 解析或元件測試）

**驗收條件**：
- [ ] 聚焦測試因功能尚未實作而預期紅燈
- [ ] 斷言五種 Story 13 情境的旗標／文案
- [ ] 斷言誤設時不得把標題畫成已開通，除非 `access_status=unlocked`

**測試策略**：Test-First（測試準備）  
> 理由：env × 會員態是明確狀態轉換。
