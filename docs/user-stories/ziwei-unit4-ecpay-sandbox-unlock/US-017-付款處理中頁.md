# US-017：付款處理中頁

**作為** 從綠界按返回商店的會員  
**我想要** 只看到處理中  
**以便** 瀏覽器回跳不能當成付款成功

**輸入格式**：
- 路徑 `/orders/processing`（對齊 `ECPAY_CLIENT_BACK_URL`）
- 不讀綠界 query 當成功；不改 `access_status`
- Webhook 未到：維持處理中；**不**做 Story 11 輪詢／QueryTradeInfo
- 「返回解讀」連到 `/`

**輸出格式**：
- `app/orders/processing/page.tsx`（或同等 App Router）

**驗收條件**：
- [ ] 畫面為處理中；帶綠界 query 也不更新 orders／權益
- [ ] 不呼叫 QueryTradeInfo
- [ ] 有返回 `/` 的連結
- [ ] 本頁不解鎖，也不因綠界 query 把 `access_status` 改回 `locked`
- [ ] 不新增 `reports.user_id`；文件或頁面註明頂層導轉會丟掉記憶體 `persist_id`，解鎖後若畫面清空需再 POST 同一生辰才能 GET 三欄

**測試策略**：Test-After  
> 理由：靜態處理中頁以畫面為主；不解鎖可用手動或輕量測試確認無寫入。
