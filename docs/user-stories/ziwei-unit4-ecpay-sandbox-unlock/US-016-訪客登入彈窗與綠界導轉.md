# US-016：訪客登入彈窗與綠界導轉

**作為** 訪客或 locked 會員  
**我想要** 點解鎖時要嘛先登入、要嘛頂層送出綠界表單  
**以便** 未登入不建單、已登入不能改價

**輸入格式**：
- 無 session：彈窗「請先登入」（可連 `/login`）；**不**打 checkout
- locked：呼叫 US-011 checkout，瀏覽器 **form POST**（非 iframe）到 Stage
- unlocked：不顯示解鎖鈕（US-015）

**輸出格式**：
- 報告鎖定區 CTA 行為（client 元件）

**驗收條件**：
- [ ] 訪客點 CTA 出現登入彈窗、無 checkout 請求
- [ ] locked 成功建單後頂層 Submit，禁止 iframe
- [ ] CTA 不呼叫 `/api/dev/grant-access`
- [ ] 忽略使用者在前端改金額

**測試策略**：Test-After  
> 理由：彈窗與 form 導轉偏 UI 互動，視覺與點擊回饋比預先斷言有效。

**優先級**：P0  
**相關功能**：Story 1／3／14  
**依賴關係**：US-011、US-015
