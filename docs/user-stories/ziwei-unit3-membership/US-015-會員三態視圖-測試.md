# US-015：會員三態視圖 測試

**作為** 開發者  
**我想要** 先有會失敗的三態旗標測試  
**以便** 畫面只消費旗標，且已開通不會被預覽假文取代

**輸入格式**：
- 函式契約（尚未實作），建議 `resolveMembershipView({ accessStatus, hasSession, previewState, previewEnabled, nickname, advanced })`
- 訪客：標題「{暱稱}的基本分析」；進階鎖定；CTA 即將開放；`slot-auth-entry`
- `locked`：同免費摘要；`slot-unlock-cta` 文案「升級／開通」；不開通
- `unlocked`：標題「{暱稱}的進階報告」；用傳入的進階真文；CTA 隱藏或「已開通」；追問仍鎖定
- `unlocked` 且 `previewEnabled`＋預覽 B：仍用真文，禁止「預覽用範例」
- 登出（無 session）：回到訪客旗標，丢掉 advanced payload

**輸出格式**：
- 對應 `*.test.ts`

**驗收條件**：
- [ ] 聚焦測試因功能尚未實作而預期紅燈
- [ ] 斷言三態標題、鎖定、CTA、追問旗標
- [ ] 斷言 unlocked + 預覽 B 不含「預覽用範例」
- [ ] 斷言無 session 時不輸出進階真文

**測試策略**：Test-First（測試準備）
> 理由：會員態 × 預覽態是明確狀態轉換。
