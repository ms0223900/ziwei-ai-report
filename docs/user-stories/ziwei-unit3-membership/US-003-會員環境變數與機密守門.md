# US-003：會員環境變數與機密守門

**作為** 開發者  
**我想要** env 留位與機密守門涵蓋 grant secret  
**以便** 前端 bundle 不會出現 service role 或 grant secret

**輸入格式**：
- 變數：`MEMBERSHIP_GRANT_SECRET`、`MEMBERSHIP_GRANT_ENABLED`（server-only）
- 既有：`NEXT_PUBLIC_SUPABASE_ANON_KEY` 本單開始給 client 用
- `lib/security/secrets-not-leaked.test.ts` 的 `SECRET_ENV_KEYS`

**輸出格式**：
- `.env.example` 新增上述 server 變數（無真實值）
- 機密守門測試列入 `MEMBERSHIP_GRANT_SECRET`
- 禁止 `NEXT_PUBLIC_MEMBERSHIP_GRANT_SECRET`

**驗收條件**：
- [ ] `.env.example` 有 `MEMBERSHIP_GRANT_SECRET`、`MEMBERSHIP_GRANT_ENABLED`
- [ ] 守門測試把 `MEMBERSHIP_GRANT_SECRET` 當禁止出現在 client
- [ ] 無任何 `NEXT_PUBLIC_*` 帶 grant secret 或 service role

**測試策略**：Test-After
> 理由：改 env 範例與既有守門名單，補跑現有測試即可。
