# US-010：更新顯示名稱

**作為** 會員  
**我想要** 在頁首改自己的顯示名稱  
**以便** 名稱出現在產品內，且改不了權益欄

**輸入格式**：
- 單列輸入 + 儲存（不是會員中心）
- Client SDK：`update({ display_name })`
- trim 後長度 ≥ 1；空白 →「請輸入顯示名稱。」
- 不覆寫報告 `nickname`

**輸出格式**：
- 頁首編輯 UI
- 成功後頁首立刻顯示新名稱

**驗收條件**：
- [ ] 改成「小園」後頁首顯示「小園」
- [ ] 空白名稱被拒，DB 值不變
- [ ] 報告卡 `nickname` 仍是生辰表單值
- [ ] Client SDK 改 `access_status`／`points_balance`／`subscription_status` 失敗，列值不變（遷移已套用為前提）

**測試策略**：Test-After
> 理由：頁首小表單與文案，適合實作後補互動測試。
