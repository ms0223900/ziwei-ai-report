# US-017：三態報告畫面

**作為** 求測者  
**我想要** 在同一份報告功能看到對應身分的內容與下一步  
**以便** 能分辨免費、未開通與已開通，且已開通也不附贈追問

**輸入格式**：
- 主驗收路徑：**先處於該身分，再生成**（不要用訪客離頁登入後的舊 `persist_id`）
- 訪客：基本摘要＋鎖定槽＋即將開放
- 已登入 `locked`：鎖定；點 `slot-unlock-cta` 顯示「開通由講師受控流程處理，本版不收費」；不改 DB
- 已登入 `unlocked`：POST 後用 `persist_id` GET，三槽填真文（含 7 天），不是「預覽用範例」
- 登出：丟掉 GET payload，三槽回佔位，頁首回 `slot-auth-entry`
- 追問框始終不可送出（本版）

**輸出格式**：
- 改 `HomeClient`／`ReportCard`／`AdvancedLockedPanel` 接 US-016 旗標與 GET
- 真文渲染 `path_compare` 物件與 `action_plan` 陣列（不要壓成單段預覽假文）

**驗收條件**：
- [ ] 訪客報告頁無進階真文，CTA 仍不收費
- [ ] 未開通 GET 失敗時畫面不露出三欄；點 CTA 不改 `access_status`
- [ ] 已開通標題為「小圓的進階報告」（示範資料），可見 7 天計畫真文
- [ ] 已開通＋預覽 B 仍是真文，不能用預覽假文驗收「已開通」
- [ ] 登出後進階真文從畫面消失
- [ ] 已開通追問仍鎖定；`points_balance` 不因開通變成正數

**測試策略**：Test-After
> 理由：報告箋接線與登出清欄屬 UI 整合，適合實作後補畫面測試。

**優先級**：P0  
**相關功能**：Story 1／6／7；spec 第 7 節問題 3／5  
**依賴關係**：US-009、US-014、US-016
