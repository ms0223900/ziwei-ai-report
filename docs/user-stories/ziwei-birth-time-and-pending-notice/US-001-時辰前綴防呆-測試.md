**輸入格式**：
- spec §2 Story A3、§3 Story A3
- `lib/validation/birth.ts` 的 `ValidatedBirth`

**輸出格式**：
- `lib/generation/birth-time-prefix.test.ts`

**驗收條件**：
- [ ] 聚焦測試因功能尚未實作而預期紅燈（失敗原因是功能缺失，不是語法錯誤；import 不存在的模組造成的失敗視為預期）
- [ ] 斷言：`birth_time="寅"`、`overall="（未知時辰，準確度較低）今天…"` → 回傳「（寅時）今天…」
- [ ] 斷言：`birth_time="寅"`、`overall="今天…"` → 回傳「（寅時）今天…」
- [ ] 斷言：`birth_time="寅"`、`overall="（寅時）今天…"` → 原樣回傳，不重複加前綴
- [ ] 斷言：`birth_time=null`（`time_unknown=true`）、`overall="今天…"` → 回傳以「（未知時辰，準確度較低）」開頭
- [ ] 斷言：`birth_time=null`、`overall` 已帶未知前綴 → 原樣回傳
- [ ] 斷言：`birth_time="寅"`、`overall` 非字串（`undefined`、數字）→ 原樣回傳，不產生「（寅時）undefined」
