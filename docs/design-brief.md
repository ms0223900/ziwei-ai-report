**本版範圍**：訪客可走完的兩個主畫面——生辰表單、未付款基本分析（畫面 A）。進階欄位鎖定；解鎖 CTA 只標記接點。**不假裝付款成功。**

## 開工計畫（6 行）

1. **色**：麻色箋 `paper` `#E8E2D4`、箋面 `sheet` `#F7F4EC`、藍黑墨 `ink` `#1E2430`、次要 `ink-soft` `#5C6573`；唯一強調印泥 `seal` `#8E1F2F`；鎖定區 `night` `#2A3344`。
2. **字**：標題 `Noto Serif TC` 700；正文／表單 `Noto Sans TC` 400／500；日期與 `report_id` 才用 `IBM Plex Mono`。
3. **版**：單欄箋本最寬 `36rem`，外邊 20–24px；中文左齊、行寬約 32–40 字；報告是一封信，不是三張卡。
4. **Signature**：行動區上方微旋 `-2°` 紅印封條，印文「未開封」；全頁只這一個記憶點。
5. **動效**：報告入場 fade 約 200ms；按鈕 hover 只加深 `seal`；尊重 `prefers-reduced-motion`。
6. **禁用**：紫漸層、奶油底＋陶土橙、Inter、星空、blur 真文、英文主按鈕、全站 16px 圓角。

對照第 12 節禁用清單後再寫碼。若任一項跟通用 AI 樣貌相似，改掉再實作。

## 1. 產品與人

**產品單一任務**：讓不懂紫微術語的訪客，用無痕視窗完成「填生辰 → 看見基本分析」，並看得出免費／付費切線。

**人**：求測者。想看個人化近況提醒，接受娛樂用途聲明。不登入。

**主語言**：繁體中文。淺白、句子短、不誓稱應驗。

**這不是**

- 官網 landing、價格表、三張功能卡
- 神壇、星空、塔羅、陰陽符、金粉紫霧
- 儀表板、會員中心、設定頁
- 英文 SaaS 樣板

**一句話**：像把一封短箋放在桌上，而不是把人推進星盤 App。

## 3. 畫面 1｜生辰表單

上下結構：產品名 → 一句話 → 表單 → 主按鈕 → disclaimer。沒有導覽列、沒有英文 logo 標語。

- 產品名用 Display 字：**紫微解讀**。不加「AI Fortune」「ZiWei GPT」。
- 副標：輸入生辰，先看基本分析。進階詳批鎖住。
- 主按鈕：**看基本分析**。不要「提交」「Generate」「開始算命」。
- 選填欄位不用 `*`。必填用文字「必填」或紅印色星號，不要只靠顏色。

| 欄位 | 必填 | 控件 | 驗證 |
|---|---|---|---|
| 暱稱 `nickname` | 是 | 單行文字 | 空白提示重填；不追問性別、出生地 |
| 生日 `birth_date` | 是 | 日期；顯示 `YYYY-MM-DD` | 格式錯或未來日期提示修正；不呼叫模型 |
| 時辰 `birth_time` | 否 | 下拉或可清空；預設空 | 空 = `time_unknown=true`；說明「未填則走未知時辰版，準確度較低」 |
| 聚焦 `focus` | 否 | 三選一分段：整體／工作／關係 | 空視為整體；不可自填其他主題 |

**錯誤文案**（出現在欄位下方，輸入框用 `warn` 邊線；不用 toast 把錯誤閃走）

- 暱稱空白：請填寫暱稱。
- 生日空白：請填寫生日。
- 格式錯：生日請用 YYYY-MM-DD，例如 1993-07-12。
- 未來日期：生日不能是未來日期。

```
+--------------------------------------+
|  紫微解讀                            |
|  輸入生辰，先看基本分析。進階詳批鎖住。 |
|                                      |
|  暱稱 *                              |
|  [ 小圓                         ]    |
|                                      |
|  生日 *                              |
|  [ 1993-07-12                  ]    |
|                                      |
|  時辰（選填）                        |
|  [ 不確定時辰                    v]  |
|  未填則走未知時辰版，準確度較低。    |
|                                      |
|  這次想看                            |
|  (整體) ( 工作 ) (關係)              |
|                                      |
|  [ 看基本分析 ]                      |
|                                      |
|  僅供娛樂與自我反思…                 |
+--------------------------------------+
```

## 4. 畫面 2｜基本分析（畫面 A）

未付款是本版唯一真實態。B／C／D 只預留同一個 DOM 位置。

### 標題區

- 標題：`{暱稱}的基本分析`
- `time_unknown=true` 必須出現標籤：「未知時辰，準確度較低」
- 若有聚焦：「聚焦工作」（示範）
- 可用細字顯示生日 `1993-07-12`；不強調 `report_id`
- 標籤之間用全形頓號或換行，**不要**中點分隔 `A · B · C`

### 可見區塊（左齊段落，不是三張卡）

每區塊：小標題（`ink-soft`）+ 1 段正文。用子筆記原文，不要改寫得更神秘。

| 標題 | 來源 | 示範文案（必須用真文） |
|---|---|---|
| 整體提醒 | `overall` | 這段時間適合先整理已有能力與成果，而不是一次做大變動。 |
| 工作 | `work` | 工作上較需要「可被看見的小成果」，而不是更多靈感。 |
| 關係 | `relationship` | 合作時把範圍講清楚，會比加更多承諾更有幫助。 |

`action` 的一句方向可放在鎖定區上方一行淡色提示，或不獨立成區。不要寫成 7 天清單。

示範 overall 若含「（未知時辰，準確度較低）」前綴，標題區標籤與正文可並存，不得刪掉準確度提示。

### 鎖定區（商業化接點）

三塊同一個外殼，由上而下佔位：

1. 行動建議 → 7 天行動
2. 依據 → `rationale`
3. 兩條路徑 → `path_compare`

每塊顯示標題 + 2–3 條不可選的灰色卡條佔位。卡條是虛構，**不得是進階 JSON 的 blur**。

封條文案：**解鎖進階報告後可見 7 天行動方針與兩條路徑比較**

付款後（交棒，不實作）：拆掉封條與佔位，在同一位置展示真正三區塊。不重算命盤。

### 解鎖 CTA

- 主按鈕：**解鎖完整報告**
- 旁白：即將開放
- 點擊：按鈕可 disabled，或展示非模態說明「解鎖即將開放，本版不收費」
- **禁止**：變成畫面 B、變成已付款、閃成功 toast、打開金流

### 追問

可不出現，或以鎖定輸入框出現，placeholder：追問需點數或訂閱。不可輸入。本版預設不出現。

### Disclaimer

報告底部與表單頁都要有（字級小一號、`ink-soft`；不要改成「僅供參考」）：

> 本結果僅供娛樂與自我反思，不作為醫療、法律、財務、投資或重大人生決策依據。

```
+--------------------------------------+
|  小圓的基本分析                      |
|  未知時辰，準確度較低  聚焦工作      |
|                                      |
|  整體提醒                            |
|  這段時間適合先整理已有能力與成果…   |
|                                      |
|  工作                                |
|  工作上較需要「可被看見的小成果」…   |
|                                      |
|  關係                                |
|  合作時把範圍講清楚…                 |
|                                      |
|  ============ 未開封 ============    |
|  行動建議                            |
|  解鎖後可見 7 天行動與兩條路徑       |
|  [佔位：三行灰條，非真實進階文]      |
|                                      |
|  依據、兩條路徑：同樣鎖定佔位        |
|                                      |
|  [ 解鎖完整報告 ]  即將開放          |
|                                      |
|  本結果僅供娛樂與自我反思。          |
+--------------------------------------+
```

## 5. 其餘狀態

### 生成中

留在表單頁或切到報告骨架。一句：**正在整理你的基本分析…**  
按鈕 loading、不可重複送出。不要全螢幕 skeleton 卡片亂舞。

### 生成失敗

文案：**這次沒有寫成報告，你可以再試一次。**  
主按鈕：再試一次。次按鈕：回表單。

API `message` 若為「生成失敗，請再試一次。」可原樣顯示；本畫面標題句用上列較完整的一句。

### 高風險

各欄改放固定句，不展整體／工作／關係命盤結論。仍保留 disclaimer。不顯示解鎖 CTA。

- 健康：這題涉及健康與醫療判斷，我不能用命盤作答。請尋求合格醫療專業人員協助。
- 法律：這題涉及法律諮詢，我不能用運勢作答。請尋求合格律師或法律援助。
- 財務／投資：這題涉及財務與投資決策，我不能用命盤或運勢給判斷。請尋求合格的金融／專業意見。
- 孕產：這題涉及孕產與身體安全，我不能用命盤作答。請尋求合格醫療專業人員協助。
- 自傷／傷害他人：若你正處於危險中，請立即尋求現場專業協助。命盤解讀不能處理這類情況。

### CTA 點擊（本版）

不離開報告頁。按鈕旁或下方一行：**解鎖即將開放，本版不收費。**

## 6. 預留：同一骨架如何變成 B／C／D

| 接點 | 本版 | 付款後（不實作） |
|---|---|---|
| 方案入口 | 解鎖完整報告 + 即將開放 | 單次解鎖後可看進階；不附贈追問 |
| 鎖定區 | 封條 + 佔位 | 展示 `rationale`／`path_compare`／`action_plan` |
| 交付位置 | 同一份報告頁 | 只打開已生成欄位，不重算 |
| 追問 | 不出現或鎖定 | 有點數或訂閱額度才可問 |

畫面 B 標題改為「{暱稱}的進階報告」。追問區文案：追問：需要點數或訂閱。

## 7. 動效

- 全頁只保留一個入場：報告箋本輕微 fade（約 200ms）
- 按鈕 hover：背景深一階（`seal-deep`），不要彈跳
- 封條不要閃爍、不要 shine sweep
- 尊重 `prefers-reduced-motion`：關掉入場
- 禁止：每區塊 stagger slide-up、數字滾動計數器、滑鼠跟隨光斑

---

## 8. 焦點與無障礙

- 可見焦點環：2px `seal`
- 標籤與輸入關聯；錯誤用 `aria-describedby`
- 對比：`ink` on `paper`、`seal` on `sheet` 都 ≥ 4.5:1（已量測，見 guideline）
- 解鎖區不只靠顏色；封條有文字
- 觸控主按鈕 ≥ 44px
- 不要用 emoji 當唯一圖示；封條用 SVG 或 CSS
- 鍵盤可完成表單

## 10. 禁用清單（AI slop）

- 紫色漸層英雄、三張一樣的功能卡、大數字 + 小標籤 KPI
- Inter／Space Grotesk／全大寫 eyebrow／中點分隔 `A · B · C`
- 標題裡單字變色、每個按鈕後縮排 `→`
- 星空、水晶球、塔羅卡牌、金粉紫霧、陰陽 fish-eye
- 用 blur 透出進階真文
- 假裝付款成功
- 英文 UI（Submit, Unlock Now, Generate My Chart）
- 追問性別或出生地
- 把基本與進階當成兩次不同命盤
- 暖奶油底 + 陶土橙、黑底鹼光綠、`#111` 假黑、裝飾性漸層洗
- 全站同一個 16px 圓角、`rgba(0,0,0,.1)` 軟陰
