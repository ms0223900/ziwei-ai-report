## 開工計畫（6 行）

1. **色**：麻色箋 `paper` `#E8E2D4`、箋面 `sheet` `#F7F4EC`、藍黑墨 `ink` `#1E2430`、次要 `ink-soft` `#5C6573`；唯一強調印泥 `seal` `#8E1F2F`；鎖定區 `night` `#2A3344`。
2. **字**：標題 `Noto Serif TC` 700；正文／表單 `Noto Sans TC` 400／500；日期與 `report_id` 才用 `IBM Plex Mono`。
3. **版**：單欄箋本。Desktop 畫布 1440、箋寬 **576**（`$sheet-max`／token `36rem` 當 max）；Mobile 畫布 **390**、箋寬 **350**。外邊 desktop 24／56、mobile 20／40。中文左齊。報告是一封信，不是三張卡。對稿看畫布寬，不是把 `window.innerWidth` 當像素真值。
4. **Signature**：行動區上方微旋 `-2°` 紅印封條，印文「未開封」；全頁只這一個記憶點。
5. **動效**：報告入場 fade 約 200ms；按鈕 hover 只加深 `seal`；尊重 `prefers-reduced-motion`。
6. **禁用**：紫漸層、奶油底＋陶土橙、Inter、星空、blur 真文、英文主按鈕、全站 16px 圓角。

對照第 12 節禁用清單後再寫碼。若任一項跟通用 AI 樣貌相似，改掉再實作。

## 1. 產品與人

**產品單一任務**：讓不懂紫微術語的訪客，用無痕視窗完成「填生辰 → 看見基本分析」，並看得出免費／付費切線。

**人**：求測者。想看個人化近況提醒，接受娛樂用途聲明。不登入。

**主語言**：繁體中文。淺白、句子短、不誓稱應驗。

**這不是**

- 官網 landing、價格表、三張功能卡
- 神壇、星空、塔羅、陰陽符、金粉紫霧
- 儀表板、會員中心、設定頁
- 英文 SaaS 樣板

**一句話**：像把一封短箋放在桌上，而不是把人推進星盤 App。

## 3. `01`｜生辰表單

上下結構：產品名 → Lead → 表單 → 主按鈕 → disclaimer。沒有導覽列、沒有英文 logo 標語。印文 **起盤**。

- 產品名用 Display 字：**紫微解讀**。不加「AI Fortune」「ZiWei GPT」。
- Lead：**依生辰起紫微原局，先批基本命理。進階詳批封存。**
- 主按鈕：**看基本分析**。不要「提交」「Generate」「開始算命」。
- 選填欄位不用 `*`。必填用文字「必填」。
- `01` 對稿預設聚焦選 **工作・官祿**（請求 `focus=工作`）。未選聚焦（省略欄位、後端當 `整體`）是 API 行為，稿沒有空選 frame。

| 畫面標籤（`.pen`） | JSON | 必填 | 控件 | 驗證 |
|---|---|---|---|---|
| 命主暱稱 | `nickname` | 是 | 單行 | 空白提示重填；不追問性別、出生地 |
| 生辰公曆（國曆） | `birth_date` | 是 | 日期 `YYYY-MM-DD` | 格式錯或未來日期提示修正；不呼叫模型 |
| 出生時辰（選填） | `birth_time` | 否 | 下拉 | 顯示「不確定時辰（走未知時辰盤）」→ `null`；其餘顯示可含時段，JSON **只送** `子`…`亥` |
| 問事宮位（排盤焦點） | `focus` | 否 | 三段：整體・命身／工作・官祿／關係・夫妻 | 請求只送 `整體`／`工作`／`關係`；空視為整體；不可自填 |

時辰 Hint：**未填時辰走未知時辰盤，準確度較低；知曉生時請選十二時辰（如卯時 05-07）。**

**錯誤文案**（欄位下方，`warn` 邊線；不用 toast）

- 暱稱空白：請填寫暱稱。
- 生日空白：請填寫生日。
- 格式錯：生日請用 YYYY-MM-DD，例如 1993-07-12。
- 未來日期：生日不能是未來日期。

`02` 只示範前兩句。格式／未來日用同一 `Field/Error` 樣式，沒有獨立畫板。


## 4. `04`｜基本分析（畫面 A）

未付款是本版唯一真實態。B／C／D 只預留同一個 DOM 位置。印文 **定局**。

### 標題區

- 標題：`{暱稱}的基本分析`（示範「小圓的基本分析」）
- `time_unknown=true` 時 overall 或標題區可見「未知時辰，準確度較低」（示範把前綴放在 overall）
- 標題用 `$font-heading`（Noto Serif TC）。標籤之間不要用拉丁中點 `A · B · C`；聚焦段的「・」是稿面用字，保留。

### ChartMatrix（裝飾，不是空框）

示範路徑（小圓）須畫出 reusable `ChartMatrix`：

- 標題：【 紫微原局・排盤總目 】
- 局名：水二局・暫定命盤
- 命主：小圓（女命）
- 生辰：西元1993年7月12日
- 歲次：癸酉年（劍鋒金）
- 問事焦點：官祿宮（工作事業）

**女命／水二局／歲次不是表單或 API 欄。** 禁止加性別輸入、禁止真排盤演算法。非示範暱稱：只換「命主：{暱稱}」（不要女命括號）、生辰改寫輸入日；局名與歲次維持稿面裝飾。

分隔線 `.pen` 用 `$line-subtle`；tokens.json 若無此 key，用 `line`，不要另造第三套色票。

### 可見區塊（左齊段落，不是三張卡）

小標跟 `.pen` **完整字串**（含局象／象意，屬裝飾，不是 JSON 欄）。正文用 basic canned，不要改寫得更神秘。

| 畫面小標 | 來源 | 示範正文 |
|---|---|---|
| 【 原局總覽 】  〔 局象：守成蓄勢 〕 | `overall` | （未知時辰，準確度較低）這段時間適合先整理已有能力與成果，而不是一次做大變動。 |
| 【 官祿事業 】  〔 象意：重在實證 〕 | `work` | 工作上較需要「可被看見的小成果」，而不是更多靈感。 |
| 【 夫妻交友 】  〔 象意：界線明晰 〕 | `relationship` | 合作時把範圍講清楚，會比加更多承諾更有幫助。 |
| 【 行動指引・破局之著 】 + 一句 | `action` | 先完成一件能展示的小交付。（不是 7 天） |

### 鎖定區

`SealStrip` 印文 **未開封**（不是標題旁 `SealStamp`；畫面 A 章是「定局」）。

三塊 `LockedBlock` 標題：

1. 【 七日轉化方略 】・密批封存
2. 【 星曜格局析理 】・密批封存
3. 【 順逆兩局抉擇 】・密批封存

佔位灰條不得是進階 JSON 的 blur。

LockCaption：**解鎖進階命書後，即啟七日行事方針與吉凶路徑析理**（舊句「解鎖進階報告後可見 7 天…」作廢）

### 解鎖 CTA

- 主按鈕：**解鎖完整報告**
- 旁白：即將開放
- 點擊（`05`）：同一 04 骨架 + **解鎖即將開放，本版不收費。**
- **禁止**：變成畫面 B、已付款、成功 toast、金流

### 追問

本版不出現。

### Disclaimer

> 本結果僅供娛樂與自我反思，不作為醫療、法律、財務、投資或重大人生決策依據。

## 5. 其餘狀態

### `03` 生成中

仍在表單箋。Lead：**正在依生辰起紫微命盤，定局排星中…**；印文 **排盤**。主鈕 `PrimaryDisabled`（仍可寫「看基本分析」）、不可連點。不要全螢幕 skeleton。

### `06` 生成失敗

僅 422／502／503。H1：**這次沒有寫成報告，你可以再試一次。** Hint = API `message`（502 示範「生成失敗，請再試一次。」）。主鈕：再試一次。次鈕：回表單。不要用短句當 H1。

欄位驗證（空白／格式／未來日）走 `02`，即使打出 HTTP 400 也不得套 06 的生成失敗 H1。

### `07` 高風險

H1：**這題我不能用命盤作答**。正文 = 該類固定句。Disclaimer。按鈕：**回表單**。無解鎖、無 ChartMatrix。五類同一版面只換正文（`.pen` Note：不另開畫面）。

- 健康：這題涉及健康與醫療判斷，我不能用命盤作答。請尋求合格醫療專業人員協助。
- 法律：這題涉及法律諮詢，我不能用運勢作答。請尋求合格律師或法律援助。
- 財務／投資：這題涉及財務與投資決策，我不能用命盤或運勢給判斷。請尋求合格的金融／專業意見。
- 孕產：這題涉及孕產與身體安全，我不能用命盤作答。請尋求合格醫療專業人員協助。
- 自傷／傷害他人：若你正處於危險中，請立即尋求現場專業協助。命盤解讀不能處理這類情況。

### `05` CTA 點擊

不離開報告頁。一行：**解鎖即將開放，本版不收費。**

## 7. 動效

- 全頁只保留一個入場：報告箋本輕微 fade（約 200ms）
- 按鈕 hover：背景深一階（`seal-deep`），不要彈跳
- 封條不要閃爍、不要 shine sweep
- 尊重 `prefers-reduced-motion`：關掉入場
- 禁止：每區塊 stagger slide-up、數字滾動計數器、滑鼠跟隨光斑

---

## 8. 焦點與無障礙

- 可見焦點環：2px `seal`
- 標籤與輸入關聯；錯誤用 `aria-describedby`
- 對比：`ink` on `paper`、`seal` on `sheet` 都 ≥ 4.5:1（已量測，見 guideline）
- 解鎖區不只靠顏色；封條有文字
- 觸控主按鈕 ≥ 44px
- 不要用 emoji 當唯一圖示；封條用 SVG 或 CSS
- 鍵盤可完成表單

## 10. 禁用清單（AI slop）

- 紫色漸層英雄、三張一樣的功能卡、大數字 + 小標籤 KPI
- Inter／Space Grotesk／全大寫 eyebrow／拉丁中點 `A · B · C`（聚焦「・」除外）
- 標題裡單字變色、每個按鈕後縮排 `→`
- 星空、水晶球、塔羅卡牌、金粉紫霧、陰陽 fish-eye
- 用 blur 透出進階真文
- 假裝付款成功
- 英文 UI（Submit, Unlock Now, Generate My Chart）
- 追問性別或出生地
- 把基本與進階當成兩次不同命盤
- 暖奶油底 + 陶土橙、黑底鹼光綠、`#111` 假黑、裝飾性漸層洗
- 全站同一個 16px 圓角、`rgba(0,0,0,.1)` 軟陰
